# /me

Who we are, so the app and the weekly coach can plan around us.

- `ben/`, `anna/`: one folder each
  - `profile.md`: background, gear, taste, goals
  - `coaching.md`: how to teach this person
  - `songs.md`: wishlist, in progress, done
  - `reviews/`: weekly coach notes (`2026-W42.md`, ...)
- `shared/duo.md`: what we're working on together

These files describe **who we are**. What we actually **did** (sessions, tempos,
chord-change counts, recordings) lives in the app's database, not here.

The coach reads both once a week, writes a short review, and adjusts goals.
Keep these short. Playing beats writing.
